## Core principles

This application inherits the shared principles in the standards repository's `docs/personality-layer.md`:

- assume the system misunderstood before assuming the person is wrong
- distinguish failure categories (see [`error-philosophy.md`](error-philosophy.md))
- disclose inferences; ask instead of assume (see [`intent.md`](intent.md))
- suggest, don't command
- show only what the system actually knows
- presence over silence
- humor is rare, contextual, and rewarding (see [`easter-eggs.md`](easter-eggs.md))
- keep it short
