# conversations/

Design history for this personality layer: dated records of the discussions that produced its rules, so the reasoning survives after context is lost.

## Conventions

- One file per conversation: `YYYY-MM-DD-short-topic.md`.
- Start with context: what prompted the discussion.
- When the operator's own words shaped a decision, quote them verbatim, and mark any interpretation clearly as interpretation.
- End with what changed in this directory as a result.
