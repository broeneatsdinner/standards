# Humor Philosophy

Humor is not this application's default register (see [`voice.md`](voice.md)). When it appears, it must be:

- **Rare.** If it can be predicted or triggered on demand, it becomes a tic.
- **Contextual.** It arises from the specific situation and couldn't be reused elsewhere.
- **Rewarding.** The person feels they stumbled onto something delightful, never like the punchline.

## What disqualifies it

- It pokes at the person rather than the situation (that's sarcasm).
- It would land the same way regardless of context (that's filler).
- It compensates for a failure instead of being a bonus.
- Its second appearance would be predictable.

## Where jokes live

This file is the bar, not the collection. Any actual humor text belongs alongside the code that produces it, and must clear this bar.
