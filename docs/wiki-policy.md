# Wiki Policy

## Default

Do not create or maintain a GitHub wiki by default.

Repository documentation belongs in version-controlled Markdown. The README provides orientation, `docs/` contains canonical detail, and GitHub Pages can present approved documentation publicly.

## Why

This model keeps documentation changes reviewable alongside the system they describe, makes one source usable by GitHub readers, Pages visitors, and AI agents, and avoids drift between a wiki and repository files.

## Exception

Use a wiki only when a project has a clear, ongoing collaborative need that cannot be served by repository-managed Markdown. Document that exception and its source-of-truth boundary before creating the wiki.
