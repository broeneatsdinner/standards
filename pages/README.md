# Pages

This directory contains the reusable GitHub Pages documentation system for consumer repositories.

The written authority lives in:

- `docs/readme-guidelines.md`
- `docs/github-pages-guidelines.md`
- `docs/wiki-policy.md`
- `docs/documentation-templates.md`
- `docs/documentation-writing-style.md`
- `docs/ai-agent-instructions.md`

`github-pages-docs-site/` is the copyable implementation kit. It provides the site shell, navigation, CSS, deployment workflow, and small example content. It is not a Pages site for this standards repository.
