# Documentation Site Agent Instructions

`docs/` is the canonical documentation source and is rendered by GitHub Pages. Do not create a second wiki or duplicate detailed documentation in the README.

Before changing this system, inspect the repository's existing README and docs. Use the standard layout by default: its right rail is generated from the current page's headings. Use the extended reference layout only when the project needs a left-side documentation tree as well.

Keep extended-layout project navigation in `docs/_data/navigation.yml`; keep shared presentation in `docs/_layouts/`, `docs/_includes/`, and `docs/assets/`. Choose orientation, guide, or reference writing mode before drafting, following the documentation writing standard.

Do not deploy Pages, publish documentation, or replace existing docs without explicit operator direction.
